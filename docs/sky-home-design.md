# Steady sky design

Reference: https://styles.refero.design/style/04109c48-f591-4110-9739-622243d4ecc2

## Visual system

- Hero: inset 12px; rounded 32–44px corners; vertical #779bc1 → #9abfda → #cbdcec gradient.
- Canvas: white. Secondary surface: #f5f5f5. Text and primary buttons: #070709. Body: #60606c.
- Accent: #2597d0, reserved for line icons and voice waveforms.
- Headings: Open Runde Semibold, 80px hero / 44px section, tracking −0.04em. Mobile hero 43px minimum, section 32px.
- Navigation: Inter. Product UI and body: Open Runde.
- Buttons and labels: full pill. Product cards: 18–22px radius, 40px desktop padding.
- Sections: centered headings, 100px desktop spacing / 72px mobile.
- Elevation: low-opacity blue shadows, broad blur.

## Steady motion

The hero pairs a looping handwritten thought with a chosen response. Three illustrative examples cycle every seven seconds. Paper cards float independently; the drawn loop traces itself; a blue waveform animates without sound. The animation is explicitly labelled as illustrative, not a clinical result or live session.

The pause control stops ambient animation and example cycling without stopping content entrances. Reduced-motion mode disables animation and automatic cycling. The live taster mounts only after selecting Meet Steady, retaining explicit microphone consent and typed interaction.

## Product boundaries

All application buttons lead to /invite. The existing questionnaire and admission rules remain the decision point. No application is submitted by the design preview or test suite. The homepage uses no clinical efficacy figures, user counts, testimonials or invented measured outcomes.
